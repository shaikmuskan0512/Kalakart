# KalaKart 🪷

KalaKart is a full-stack MERN e-commerce platform for discovering and shopping Indian handlooms, handicrafts, and traditional products from different regions of India.

## Features

- User Registration & Login
- Product Search
- Product Categories
- Filters by Category, State, Price & Rating
- Wishlist
- Shopping Cart
- Quantity Management
- Checkout
- Shipping Address
- Order Placement
- Previous Orders
- Responsive Design

## Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- MongoDB Atlas
- JWT
- bcrypt
